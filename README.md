# Celestial Bodies Database

This repository contains the database dump for the **Celestial Bodies Database** project, completed as part of the **freeCodeCamp Relational Database Certification**.

## Project Overview
The PostgreSQL database (`universe`) models a celestial ecosystem with full relational integrity and constraints. It consists of 5 interconnected tables:
- `galaxy_type` - Categorization of galaxies
- `galaxy` - Details of observed galaxies
- `star` - Stars mapped to their parent galaxies
- `planet` - Planets mapped to host stars
- `moon` - Moons mapped to their host planets

## Contents
- `universe.sql`: The complete PostgreSQL database dump containing table schemas, relations, constraints, and dataset entries.
